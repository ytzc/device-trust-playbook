Device Identity

IDevID（出廠終身）和 LDevID（現場可換）遵循 IEEE 802.1AR，私鑰保護在 TPM/hRoT（non-exportable）。EK → IDevID → LDevID 的 proof-of-possession 繼承鏈。

⚓

Root of Trust

信任鏈起點。hTPM（x86）· fTPM（ARM TrustZone TA）· Soteria hRoT（TX8 AHB，非標準 TPM API）· SE（Legacy 補強）· PUF（Key derivation 基礎）。vTPM 僅 CI/測試。

🏭

Secure Provisioning & Onboarding

FDO（FIDO Device Onboard）：DI→OV→TO1→TO2，IoT 零觸碰，OV 轉移所有權。BRSKI（RFC 8995）：IDevID→MASA→LDevID，網路設備自動上線。TTPS DI 提供整合平台。

🔒

Firmware Integrity

Secure Boot（守門員，驗簽，失敗不開機）→ Measured Boot（記錄員，hash 存 PCR）→ 提供 evidence 給 Remote Attestation。SBOM（SPDX/CycloneDX）滿足 CRA Part II(1)。

📡

Remote Attestation

IAK（出廠）→ LAK（現場）→ TPM2_Quote 簽名 PCR 快照 → NMS Verifier Pass/Fail。IETF RATS（EAT/CoRIM）標準 evidence 格式。TX8 Soteria 的 RA 能力 ❌TBC。

🇪🇺

CRA Readiness

EU CRA 2024/2847 全面強制執行 2027-12-11。FiduciaEdge 提供 CRA-ready technical foundation + evidence 準備，法律 conformity assessment 責任在 OEM。Annex I 21 條文英中對照頁可查閱。
